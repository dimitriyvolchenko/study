# Проверка сборки — 28 сентября 2026

Проверено автоматически:

- синтаксис JavaScript;
- перенос старого формата v3;
- объединение независимых отметок, дат занятий и дней привычек с двух устройств;
- сохранение корзины Habits при синхронизации и восстановление раздела на другом устройстве;
- снятие отметок, удаление привычек и групп, переименование одновременно с отметкой дня;
- повторное объединение одних и тех же данных;
- запуск логики интерфейса всех четырёх профилей в jsdom;
- пять кнопок меню, переходы Sudak и Habits, возврат блока привычек на Menu;
- отображение стадий уроков и отдельные кнопки Word Pack;
- независимость отметок урока и Word Pack для English и Bashkir, отдельная строка каждого пака и появление выбранной эмодзи в трекере Habits;
- последовательность из пяти нажатий на кнопку удаления раздела, перенос вместе с привычками в Cloud recycle bin и полное восстановление;
- наличие курсов мамы и сохранение имени progress_mama.json;
- отсутствие переноса старого общего состояния папы в новый профиль мамы;
- чтение и объединение данных перед записью GitHub, повтор после 409;
- сохранение очереди без сети, отправка после восстановления связи;
- сохранение изменений, сделанных во время отправки;
- отказ от импорта файла другого профиля;
- сохранение локальных данных при ошибке доступа GitHub 403;
- service worker в тестовом окружении: установка кэша, выдача index.html, скриптов и курсов без сети, исключение файлов прогресса из кэширования.
