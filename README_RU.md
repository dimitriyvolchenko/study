# Study Noodle House — обновление PWA

## Что изменилось

- Меню: **Menu → Sudak → Habits → Marks → Cloud**. Иконка Sudak — линейная волна. Sudak открывает прежний общий маршрут по кнопке N; сама N сохранена.
- Habits доступны и внизу Menu, и на отдельной странице. Это одни и те же привычки и данные.
- Под привычками появились **Sections** и **Word Pack**. Названия разделов добавляются автоматически, включая разделы из новых проектов; в Word Pack есть отдельная строка для каждого пака.
- В Sections показана маленькая эмодзи последней отмеченной стадии урока за соответствующий день. Зелёной заливки нет. Если за день отмечено несколько уроков раздела, отображается последняя действующая отметка.
- В Word Pack — независимые стадии каждого пака: компактные эмодзи в чёрных кружках. Выбирать их нужно в строке **Word Pack** у пака на странице Sudak. Верхние кнопки стадий урока управляют только уроком. Отметки паков и уроков не затирают друг друга; отдельно проверены English и Bashkir.
- У раздела Habits есть круглая кнопка удаления рядом с плюсом. Нажмите её пять раз подряд: появится наклонный крестик. Нажатие на крестик перемещает раздел вместе с привычками в корзину **Cloud → Habits recycle bin**. Корзина синхронизируется между устройствами; восстановить раздел можно из Cloud.
- Сохранены четыре профиля, прежние пароли, идентификаторы уроков и файлы прогресса. В комплект включены все пять предоставленных курсов, в том числе ЕГЭ и Starlight 9 для мамы. Более новые установленные версии курсов не заменяются старой версией из комплекта.
- Автоматическая установка сохраняет приложение и пять курсов для запуска без сети. Новые внешние материалы доступны офлайн после их загрузки на устройство.

## Как обновить GitHub Pages без потери прогресса

1. Перед обновлением в каждом используемом профиле откройте **Cloud → Backup → Download file** и сохраните резервный файл. Дождитесь сохранения текущего прогресса на GitHub.
2. Распакуйте архив. В репозитории загрузите его содержимое **в ту же папку, где сейчас лежит `index.html`**. Замените `index.html`; добавьте `sw.js`, `sync-core.js`, `pwa.css`, `manifest.webmanifest`, папки `icons` и `bundled`.
3. **Существующие `progress.json`, `progress_mama.json`, `progress_yulia.json`, `progress_seryozha.json`, папку `packages` и дополнительные уроки оставьте на месте.** В архиве нет файлов прогресса, поэтому он их не подменяет. Не заменяйте весь репозиторий пустой папкой.
4. Сохраните прежний домен, адрес сайта и настройки публикации GitHub Pages. Локальные данные привязаны к адресу сайта. Открывайте HTTPS-адрес опубликованного сайта, а не страницу файла на github.com и не скачанный HTML через приложение «Файлы».
5. После публикации откройте сайт с интернетом на каждом устройстве. Закройте старые вкладки с прежней версией и откройте сайт заново. До возобновления занятий обновите устройства всех членов семьи: старый код синхронизации не знает о новых данных и правилах объединения.
6. В **Cloud → Offline · PWA** дождитесь надписи **Ready offline**. Если загрузка не удалась, нажмите **Download for offline use**. Первоначальная загрузка включает крупный HTML со встроенными материалами и все пять курсов, поэтому дайте ей завершиться.
7. На iPhone откройте сайт в Safari и добавьте на экран «Домой» как веб-приложение. В установленном приложении также один раз откройте нужный профиль при наличии интернета, дождитесь загрузки и проверьте прогресс. Если настройки Cloud не перенеслись из Safari, импортируйте прежний файл ключа через Cloud. Не очищайте данные Safari для установки обновления.

`README_RU.md` и `TEST_REPORT.md` можно хранить в репозитории для справки; для работы приложения они не нужны. Для последующих выпусков разработчик должен менять `VERSION` в `sw.js`. Когда новая версия готова, в Cloud появится кнопка **Update app**.

## Как работает синхронизация

Сначала изменение записывается на устройство. При наличии ключа и связи приложение отправляет его на GitHub. Без сети очередь остаётся после закрытия приложения. При следующем открытии или возвращении в приложение онлайн отправка повторяется; пока приложение открыто, повторные попытки выполняются также периодически.

Перед записью приложение читает файл соответствующего профиля и объединяет изменения. Независимые отметки уроков, дни занятий, названия привычек и их ежедневные отметки объединяются отдельно. Снятые отметки учитываются как изменения. Для одного и того же поля используется более поздняя отметка времени; дата и время на устройствах должны быть правильными. При конфликте версии GitHub чтение и объединение повторяются.

Word Pack, история новых стадий по дням и результаты проверок включены в резервный файл. Состояние каждого отдельного урока переносится целиком по более позднему изменению; две параллельные сессии одного урока не объединяются по каждому ответу. Настройки внешнего вида остаются локальными.

Закрытое приложение на iPhone не обязано синхронизироваться в фоне. Откройте его после возвращения связи и дождитесь успешного сохранения. Удаление данных сайта или приложения может удалить ещё не отправленные изменения; резервный файл полезно хранить отдельно.

## Проверка на iPhone после установки

1. В каждом семейном профиле проверьте прежние отметки и названия курсов. У мамы должны быть English · EGE и Starlight 9.
2. Дождитесь **Ready offline**, закройте приложение свайпом, включите авиарежим и откройте его снова. Откройте ранее загруженный урок.
3. Отметьте урок трубой. В Habits → Sections напротив соответствующего раздела за сегодняшний день должна появиться 🔭.
4. В Sudak в строке Word Pack поставьте сердечко. В Habits → Word Pack у этого пака появится ❤️ в чёрном кружке; отметка урока останется независимой.
5. Проверьте удаление тестового раздела привычек: пять нажатий на круг, затем наклонный крестик; восстановите раздел из корзины Cloud.
6. Закройте приложение и откройте снова без сети: отметки должны сохраниться.
7. Верните интернет, откройте приложение и дождитесь синхронизации. На другом устройстве откройте тот же профиль и проверьте обе отметки.
8. На двух устройствах поставьте отметки в разных уроках. После синхронизации обе должны сохраниться. Снимите одну отметку и проверьте, что она не возвращается.

## Если что-то пошло не так

Не нажимайте Clear all marks и не очищайте данные браузера. Сначала экспортируйте локальный прогресс из Cloud. Проверьте правильность профиля, адрес сайта и настройки репозитория. При ошибке доступа к GitHub локальные изменения остаются в очереди; восстановите доступ и повторите Save progress.

При первом запуске новая версия также сохраняет локальный снимок старого состояния для диагностики. Он не заменяет скачанную резервную копию.
