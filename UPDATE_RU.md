# Study — сборка 2026-09-28-7 · Rocket

## Sudak / Word Pack

Пак появляется только тогда, когда в исходном разделе у соответствующего этапа стоит 🔭, 🏗️ или ❤️. Без отметки или с 🔋 в исходном разделе пак скрыт. Повторная смена отметки на 🔭, 🏗️ или ❤️ снова показывает его.

В Sudak у пака собственные отметки. Даже 🔋 не скрывает пак и не меняет исходный этап. По согласованию сохранено только отображение завершения пака чёрным кружком в Habits → Word Pack. История отметок и прежние ключи прогресса сохранены.

## Rocket

Нажмите круглую 🚀 под кодом этапа. Этап переместится над блоками своего раздела и появится на общей странице Rocket. Повторное нажатие возвращает его в исходный блок. Выбор сохраняется до отмены; автоматического сброса ночью нет.

Нижнее меню: Menu → Sudak → Rocket → Habits → Cloud. Marks находится внизу Cloud внутри раскрывающегося блока Show / Hide.

## Блоки

В каждом блоке не более пяти этапов. Номер сверху — меню для перемещения всего блока на другую позицию. Toggle включает и выключает приглушение блока. Выбранные этапы, порядок блоков и Toggle синхронизируются отдельно для каждого профиля.

## Аккаунты и ключ

Из уже открытого профиля папы нажатие на другой семейный профиль сразу переключает аккаунт без пароля. На экране входа и в остальных профилях прежние проверки паролей сохраняются.

Cloud → GitHub: Save key to the app сохраняет ключ только в текущем браузере на текущем устройстве. Copy the key from the app копирует его в буфер обмена. Ключ не включается в общий файл прогресса или файлы сайта. На другом устройстве ключ нужно вставить или импортировать отдельно.

## Бэйдж iPhone

Если браузер поддерживает Badging API, счётчик Rocket передаётся на значок приложения. В Cloud появляется Enable Rocket badge. На iPhone сайт должен быть установлен на домашний экран; для отображения бэйджа необходимо разрешение на уведомления. При открытом приложении и после синхронизации счётчик обновляется. Изменения на другом устройстве при закрытом приложении не доставляются через push.

На реальном iPhone эта сборка не проверялась. Реализация вызовов API и изменение числового счётчика проверены в тестовом окружении.

## Загрузка на GitHub

Распакуйте полный ZIP. Загрузите его содержимое в корень репозитория с заменой одноимённых файлов. Папки icons и bundled должны остаться настоящими папками. Не удаляйте progress*.json, packages и другие пользовательские материалы. В новой версии обязательно обновите index.html, pwa.css, sync-core.js и sw.js вместе.

После публикации откройте сайт онлайн и примените Update app в Cloud. В Cloud должна появиться надпись Build 2026-09-28-7 · Rocket. Затем закройте приложение и откройте снова. Если надпись старая, новая сборка ещё не применена.
