Что сделано
- Вкладка W переработана.
- Основной шаблон теперь основан именно на приложенном пользователем чистом файле желтого Walkman.
- Во вкладке W добавлена галерея миниатюр, чтобы выбирать, какую обоину использовать.

- Генератор по-прежнему работает в режимах W1 и W2.

Новая логика W
1. Открываешь вкладку W.
2. Выбираешь режим:
   - make W1 — один подраздел из 5 слов;
   - make W2 — два подраздела по 5 слов.
3. Выбираешь миниатюру нужной обоины.
4. Выбираешь подраздел(ы) из выпадающих списков.
5. Нажимаешь make the wallpaper.
6. PNG создается программно и отправляется на скачивание.

Что входит в шаблоны
- Walkman yellow — точный attached clean source file.
- Несколько дополнительных Walkman-вариантов.
- Несколько вариантов в духе Nokia 3310.
- Несколько вариантов в духе Retro / Kodak.

Какие файлы заменить

Как проверить
1. Открыть приложение.
2. Перейти во вкладку W.
3. Убедиться, что видны миниатюры шаблонов.
4. Выбрать один шаблон.
5. Выбрать подраздел(ы).
6. Нажать make the wallpaper.
7. Должен появиться preview и запуститься скачивание PNG.

Замечание
- Для iPhone прямое скачивание через PWA / Safari может вести себя по-разному.
- Даже если файл не скачивается сразу, изображение должно открываться, после чего его можно сохранить в Фото.
